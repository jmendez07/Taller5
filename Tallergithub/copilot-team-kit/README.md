# Copilot Team Kit - Taller 5

Este kit acompaña el taller **IA Avanzada y Escalamiento de Equipos**. Su objetivo es ayudar a los participantes a convertir buenas prácticas individuales con GitHub Copilot en activos reutilizables para equipos de datos y analítica.

## Contenido

- `custom-instructions-equipo.md`: plantilla para definir estándares de uso de Copilot, incluyendo dónde colocar archivos en el repositorio.
- `libreria-prompts.md`: estructura inicial para prompts reutilizables con guía de implementación como archivos `.prompt.md`.
- `checklist-code-review-ia.md`: lista de verificación para revisión asistida por IA con antipatrones, trazabilidad, y secciones de gobernabilidad, observabilidad y evaluación.
- `canvas-agente-especializado.md`: plantilla para diseñar un agente con gobernabilidad, observabilidad, evaluación, ruta de implementación y evolución progresiva.

## Uso en el taller

1. Completar primero las instrucciones del equipo.
2. Crear al menos tres prompt cards reutilizables.
3. Probar la lista de verificación de revisión con un ejemplo SQL, Python o notebook.
4. Diseñar un agente especializado usando el canvas.
5. Presentar el acelerador al cierre del taller.

## Criterio de salida

El entregable debe ser específico, reutilizable y gobernado. Si otro equipo no puede entender cuándo usarlo, qué entradas requiere y cómo validar la salida, todavía necesita refinamiento.
